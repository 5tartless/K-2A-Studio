## This is an experimental version for future purposes of K2A-Studio
This experiment is entirely developed by 5tartless.
If it overcomes in someway or results promising to everyone then pyqt5 will get replaced.
It's an Experiment.

The main idea is to convert K2A-Studio into an Electron app that links with python for the AI and thus improve code and app communication.

Also allowing us to make the app feel modern and more polished visually.

Pyqt5 isn't bad. But I still want to experiment with Electron just because it seems promising and we have gained web development experience.
